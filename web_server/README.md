# web_server

Introduction to web servers: transferring files with `scp`, installing and
configuring Nginx, and setting up a domain name.

## Files

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server's home directory with `scp`. |
| `1-install_nginx_web_server` | Installs Nginx and serves a page containing `Holberton School`. |
| `2-setup_a_domain_name` | The domain name pointing to the web-01 server. |
| `3-redirection` | Configures `/redirect_me` as a 301 redirect. |
| `4-not_found_page_404` | Configures a custom 404 page containing `Ceci n'est pas une page`. |
| `5-design_a_beautiful_404_page.html` | A designed 404 page. |
